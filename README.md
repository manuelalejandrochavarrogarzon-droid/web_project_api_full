# Around the U.S. — Full Stack

Aplicación web full stack que permite a los usuarios registrarse, iniciar sesión, gestionar su perfil y avatar, crear tarjetas con imágenes e interactuar con las tarjetas disponibles.

## Funcionalidades

- Registro de usuarios.
- Inicio de sesión mediante JWT.
- Autenticación y protección de rutas.
- Consulta y actualización del perfil.
- Actualización del avatar.
- Creación y eliminación de tarjetas.
- Gestión de likes en las tarjetas.
- Persistencia de datos mediante MongoDB.
